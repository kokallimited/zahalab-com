How we work

Tools that respect you

Password generators, analysers and calculators run entirely in your browser. What you type into them is never sent to a server, because there is no server behind the tool.

Honest recommendations

Some links earn us a commission. It never decides what we feature or how we rank it, we say when we have not tested something ourselves, and every site carries a full affiliate disclosure and privacy policy.

Minimal data

No accounts, no tracking pixels, no data sales. Optional analytics load only after you accept them on the cookie banner.

Built to last

Fast static pages, no pop-ups, no dark patterns. Pages stay useful without an account, a paywall or an app install.
